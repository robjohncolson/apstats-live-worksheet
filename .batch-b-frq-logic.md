(function(window){

### Function 1: `getFrqDecomposition(questionId)`

Signature: `(questionId: string) => DecompEntry | null`

Behavior:
- Returns `window.FRQ_DECOMPOSITIONS[questionId]` if it exists.
- Returns `null` if `window.FRQ_DECOMPOSITIONS` is falsy.
- Returns `null` if `questionId` is not a non-empty string.

### Function 2: `recordHelperUsed(unit, kind, payload, state)`

Signature: `(unit: number, kind: 'formula'|'mcq-correct'|'mcq-wrong', payload: string, state: object) => void`

Parameters:
- `unit`: integer 1-9
- `kind`: one of 'formula', 'mcq-correct', 'mcq-wrong'
- `payload`: string (formulaId for 'formula'; questionId for MCQ kinds)
- `state`: the global state object; must have `state.units[unit]`

Behavior:
1. Ensure `state.units[unit].frqHelpers` exists. If absent, initialize to:
   ```js
   { formulasViewed: [], mcqDrills: {}, confirmed: false, activeDrillQuestionId: null }
   ```
2. `kind === 'formula'`: if `payload` already in `frqHelpers.formulasViewed`, no-op. Otherwise `frqHelpers.formulasViewed.push(payload)`.
3. `kind === 'mcq-correct'`: if `payload` already a key in `frqHelpers.mcqDrills`, no-op (first-use wins). Otherwise `frqHelpers.mcqDrills[payload] = 'correct'`.
4. `kind === 'mcq-wrong'`: if `payload` already a key in `frqHelpers.mcqDrills`, no-op (first-use wins). Otherwise `frqHelpers.mcqDrills[payload] = 'wrong'`.
5. Mutate in-place, return `undefined`.
6. If `payload` is not a string or empty, no-op.
7. If `kind` is unknown, no-op.

### Function 3: `computeEffectivePenalty(frqHelpers, decomposition)`

Signature: `(frqHelpers: object | null, decomposition: DecompEntry | null) => number`

Returns: number in `[0, 0.50]`.

Behavior:
1. If `frqHelpers` is falsy or `decomposition` is falsy, return 0.
2. Build the set of all formula IDs that appear in ANY skill's `supportingFormulas[]` in `decomposition.skills` (use `new Set()` to dedupe across skills).
3. For each unique `formulaId` in `frqHelpers.formulasViewed`: if it's in the set from step 2, add `0.05` to the running total. (Dedupe `formulasViewed` with a Set in case the state has duplicates — defensive.)
4. For each key in `frqHelpers.mcqDrills`:
   - If value === `'correct'`: add `0.10`
   - If value === `'wrong'`: add `0.15`
5. Cap result at `decomposition.maxPenalty` (use `0.50` if `maxPenalty` is missing or not a number).
6. Floor at 0.
7. Return as a number with normal float precision (no rounding at this layer).

### Function 4: `computeEffectiveScore(rawScore, penalty)`

Signature: `(rawScore: 'E'|'P'|'I'|'paper', penalty: number) => { raw, rawNumeric, effective, penaltyPct, breakdown }`

Returns an object with fields:
```js
{
  raw: string,                 // 'E' | 'P' | 'I' | 'paper'
  rawNumeric: number | null,   // E→1.0, P→0.6, I→0.2, paper→null
  effective: number | null,    // rawNumeric * (1 - penalty), rounded to 2 decimals. null if paper.
  penaltyPct: number,          // Math.round(penalty * 100). 0 if paper.
  breakdown: []                // always [] — caller builds breakdown text
}
```

Behavior:
- Paper mode (`rawScore === 'paper'`): return `{ raw: 'paper', rawNumeric: null, effective: null, penaltyPct: 0, breakdown: [] }`.
- Unknown `rawScore`: treat as `'I'` (rawNumeric = 0.2).
- Otherwise:
  - `rawNumeric`: E→1.0, P→0.6, I→0.2
  - `effective`: `Math.round(rawNumeric * (1 - penalty) * 100) / 100`
  - `penaltyPct`: `Math.round(penalty * 100)`
  - `breakdown`: `[]` (always)
- If `penalty` is not a finite number, treat as 0.
