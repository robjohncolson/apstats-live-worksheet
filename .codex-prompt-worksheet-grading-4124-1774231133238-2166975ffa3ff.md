    <strong>Learning Objectives:</strong>
    <ul style='margin: 8px 0 0 0; padding-left: 20px;'>
        <li>Calculate expected counts in a two-way table using row totals, column totals, and the table total.</li>
        <li>Explain that expected counts in a two-way table are based on the assumption of no relationship between the variables.</li>
        <li>Use the expected-count formula for specific cells in a two-way table.</li>
        <li>Use row totals, column totals, and subtraction to find remaining expected counts efficiently.</li>
        <li>Distinguish observed counts, expected counts, and total cells in a two-way table.</li>
    </ul>
    <strong style='margin-top: 10px; display: block;'>Essential Knowledge:</strong>
    <ul style='margin: 8px 0 0 0; padding-left: 20px;'>
        <li>A two-way table summarizes data for two categorical variables.</li>
        <li>Expected counts in a two-way table are calculated assuming there is no relationship between the row and column variables.</li>
        <li>Before finding expected counts, you need the row totals, the column totals, and the table total.</li>
        <li>The expected count for any cell is (row total &times; column total) / table total.</li>
        <li>The formula can be understood by applying an overall row proportion to a specific column total.</li>
        <li>Once some expected counts are known, the remaining interior cells can often be found by subtraction.</li>
        <li>Expected counts are found only for the interior cells of the table, not for the totals.</li>
        <li>If expected counts are shown in parentheses, a clear key should identify them.</li>
    </ul>
</div>

    <h3>Key Vocabulary</h3>
    <table class='vocab-table'>
        <tr><td>Two-Way Table</td><td>A table that summarizes counts for two categorical variables.</td></tr>
        <tr><td>Expected Count</td><td>The count predicted for a cell if there is no relationship between the two variables.</td></tr>
        <tr><td>Observed Count</td><td>The actual count recorded in a cell of the table.</td></tr>
        <tr><td>Row Total</td><td>The total count across one row of the table.</td></tr>
        <tr><td>Column Total</td><td>The total count down one column of the table.</td></tr>
        <tr><td>Table Total</td><td>The grand total of all counts in the table.</td></tr>
        <tr><td>No Relationship</td><td>The assumption that the row and column variables are not associated.</td></tr>
        <tr><td>Cell</td><td>A single interior box in a two-way table where a row and column meet.</td></tr>
        <tr><td>Subtraction Shortcut</td><td>Using row totals and column totals to find remaining expected counts after some are calculated.</td></tr>
        <tr><td>Key</td><td>A label that explains what numbers in parentheses represent.</td></tr>

                    }

                    const matchedCount = (result.matched || []).length;
                    const missingCount = (result.missing || []).length;
                    const totalElements = matchedCount + missingCount;
                    const hitRate = totalElements > 0 ? matchedCount / totalElements : 0;

                    if (result.score === 'P' && hitRate >= 0.3 && missingCount > 0) {
                        btn.textContent = '\u2728 Polishing...';
                        try {
                            const enriched = await fetchEnrichedAnswer(id, answer, result.missing);

                        } catch (err) {

                        }
                    }
                    // --- End Enriched Pass ---

                    gradingState.set(id, { result, originalAnswer: answer, appealCount: 0, history: [] });
                    showFeedback(id, result);

                    console.error('Grading error:', err);
                    showFeedback(id, { score: 'I', feedback: 'Error grading response. Please try again.' });
