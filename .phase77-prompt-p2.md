Phase 77 Priority 2 — Jump-Table Slot Scan for Token Helpers (TI-84 CE ROM transpilation)

## Goal
Find jump-table (BCALL) slots that target the 0x0a0300-0x0a0500 region (neighborhood of the TI-BASIC token table at 0x0a0450). Those slots ARE the public BCALL entries for token-name printing. Then find their callers and probe them.

## Context
Phase 74 found that mode names like "Normal"/"Float" live at 0x0a0450 as `<token_code><length><name>` entries. Phase 75 found NO direct `ld hl, 0x0a0450` loads in the lifted code — token access is via BCALL (the `rst 0x08 ; db <slot_lo> ; db <slot_hi>` pattern) or offset computation. The JT dispatch lookup lives at 0x020104 (980 × 3-byte little-endian 24-bit addresses). Find slots with targets near the token table.

## Deliverables (all files in TI-84_Plus_CE/)

### 1. `probe-phase77b-jt-token-helpers.mjs`
Node script that:
- Reads ROM.rom (4MB) via `fs.readFileSync`
- Walks the jump table at 0x020104. Each slot N has its 24-bit target at `ROM[0x020104 + N*3] | (ROM[0x020104 + N*3 + 1] << 8) | (ROM[0x020104 + N*3 + 2] << 16)`. Iterate N=0..979.
- Collects slots whose target falls in 0x0a0300-0x0a0500 (token-table neighborhood), 0x0a0400-0x0a0600 (token table itself), and 0x009000-0x00a000 (near char-print at 0x0059c6 — also print for completeness)
- For each matched slot, scan ROM.rom for BCALL patterns that dispatch to this slot. BCALL pattern: `rst 0x08 ; dw <slot_offset>` where slot_offset is a 2-byte little-endian value. Important: the BCALL opcode is **0xEF** (ADL) or the `rst 08h` encoding — check both. In lifted code, BCALLs often appear as `rst 0x08 ; db <lo> ; db <hi>` where `(hi<<8)|lo` is the slot OFFSET (slot_index × 3, not slot_index itself). Another common encoding is `call 0x020104 + N*3` directly.
- For each matched slot, ALSO scan the lifted blocks (PRELIFTED_BLOCKS from ROM.transpiled.js) for dasm containing `rst 0x08` followed by the correct slot offset OR `call 0x020104+N*3`. List caller addresses.
- For each distinct caller function entry, run a probe using the OS-init prelude from `probe-phase64-0a1cac-novel-callers.mjs`. Probe with HL=0x0a0452, A=0x4F (Normal token code), IY=0xD00080, maxSteps=12000.
- Also probe each matched SLOT TARGET directly (even without known callers) with HL=0x0a0452, A=0x4F.
- Capture VRAM writes, fg/bg counts, bbox, and first 10 blocks executed.
