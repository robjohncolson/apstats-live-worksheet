Topic 1.3: Topic 1.3

Representing a Categorical Variable with Tables
Video Follow-Along Worksheet
Learning Objectives:
  • Represent categorical data using a frequency table.
  • Represent categorical data using a relative frequency table.
  • Convert category counts into proportions or percentages.
  • Describe categorical data using counts and relative frequencies.
  • Use table values to justify claims about categorical data in context.
Essential Knowledge:
  • A frequency table gives the number of cases falling into each category.
  • A relative frequency table gives the proportion or percent of cases falling into each category.
  • Percentages, relative frequencies, and rates provide the same information as proportions.
  • Counts and relative frequencies reveal information that can be used to justify claims about the data in context.
  • Categorical variables are described by comparing categories and how common they are.
  • A majority means at least 50% of the cases.

Key Vocabulary

Frequency TableA table that shows the number of cases in each category.
Relative Frequency TableA table that shows the proportion or percent of cases in each category.
FrequencyThe count of individuals in a category.
Relative FrequencyThe proportion or percent of individuals in a category.
CaseAnother word for an individual in a data set.
CategoryA possible value or label for a categorical variable.
ProportionA part divided by the whole, often written as a decimal or fraction.
PercentA proportion written out of 100.
DistributionHow the values of a variable are spread across categories.
MajorityMore than half, or at least 50%, of the cases.
