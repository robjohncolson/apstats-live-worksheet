AP Statistics Unit 6 Inference for Proportions

Topic 6.7: Potential Errors When Performing Tests

Type I Error, Type II Error, and Power
Video Follow-Along Worksheet
Learning Objectives:
  • DAT-3.B: Identify and interpret Type I and Type II errors in context.
  • DAT-3.C: Explain power and describe factors that affect the probabilities of errors in significance testing.
Essential Knowledge:
  • A Type I error occurs when H0 is true and is rejected; this is a false positive.
  • A Type II error occurs when H0 is false and is not rejected; this is a false negative.
  • The probability of a Type I error equals α, and the probability of a Type II error equals 1 minus power when power is given.
  • Power increases when sample size increases, significance level increases, standard error decreases, or the true parameter value is farther from the null.

Key Vocabulary

Type I Error Rejecting H0 when H0 is actually true.
Type II Error Failing to reject H0 when H0 is actually false.
False Positive Another name for a Type I error: concluding there is convincing evidence for Ha when there really is not.
False Negative Another name for a Type II error: failing to find convincing evidence for Ha when Ha is actually true.
Power The probability that a test will correctly reject a false null hypothesis.

Key Takeaways

[Summary]
  1. Type I error: reject H0 when H0 is actually true. This is a false positive.
  2. Type II error: fail to reject H0 when H0 is actually false. This is a false negative.
  3. The probability of a Type I error is α; the probability of a Type II error is 1 minus power.
  4. Power gets larger when sample size or α increases, standard error decreases, or the true parameter is farther from the null value.
