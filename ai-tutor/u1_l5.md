**[MCQ] U1-L5-Q01**

Which of the following describes a continuous variable?

(A) The number of items sold at a craft booth for one day
(B) The number of apps downloaded from a website one day
(C) The diameters of the tree trunks at an evergreen farm
(D) The number of baskets made by a basketball player
(E) The shoe sizes of all shoes on sale at a department store

KEY: C

WHY (for the tutor's eyes; never reveal verbatim): This item tests LO UNC-1.F / EK UNC-1.F.1 and UNC-1.F.2 — the core discrete-vs-continuous distinction. Choices A, B, and D are all counts (items sold, apps downloaded, baskets made), which are by definition discrete: they take on a countable, whole-number set of values with gaps between them (EK UNC-1.F.1). Choice E (shoe sizes) is also discrete because shoe sizes come in fixed increments (e.g., 7, 7.5, 8) — a countable set. Only C (diameters of tree trunks) is a measurement: a diameter can take on infinitely many values within any interval, and no matter how close two diameter measurements are, another value always exists between them (EK UNC-1.F.2). The top distractor is likely E: students may think "shoe sizes include half-sizes so they're continuous," but half-sizes are still a countable, fixed set of values — they do not fill every real number in an interval. Redirect students who pick E to EK UNC-1.F.1 ("countably infinite" still means discrete) vs. UNC-1.F.2 (truly continuous means you can always find a value in between any two values).

**[MCQ] U1-L5-Q02**

Data will be collected on the following variables. Which variable can be considered discrete?

(A) The height of a person
(B) The weight of a person
(C) The length of a person's arm span
(D) The time it takes for a person to solve a puzzle
(E) The number of books a person finished reading last month

KEY: E

WHY (for the tutor's eyes; never reveal verbatim): This item tests LO UNC-1.F / EK UNC-1.F.1 and UNC-1.F.2 — the ability to identify a discrete variable among continuous ones. Choices A (height), B (weight), C (arm span), and D (time) are all measurements on a continuous scale: between any two values, another value can always be found, and the set of possible values is not countable (EK UNC-1.F.2). Choice E (number of books finished) is a count — it can only be 0, 1, 2, 3, … — a finite, countable set with gaps (e.g., you cannot finish 2.7 books), matching EK UNC-1.F.1. The key teaching move: ask the student whether each option comes from counting or measuring (the worksheet's heuristic from the lesson video). Students who pick D may confuse "time can be short/discrete-looking in context" with the mathematical definition — redirect them to UNC-1.F.2: can you always find another time value between any two times? Yes, so it's continuous.

**[MCQ] U1-L5-Q03**

The following list shows the number of video games sold at a game store each day for one week.

15, 43, 50, 39, 22, 16, 20

Which of the following is the best classification of the data in the list?

(A) Categorical and continuous
(B) Quantitative and continuous
(C) Categorical and discrete
(D) Quantitative and discrete
(E) Neither categorical nor quantitative, and neither discrete nor continuous

KEY: D

WHY (for the tutor's eyes; never reveal verbatim): This item tests LO UNC-1.F / EK UNC-1.F.1 applied alongside the categorical-vs-quantitative distinction from Topic 1.2 (LO VAR-1.A). The data are counts of video games sold — numerical values for which arithmetic (e.g., finding the mean) is meaningful, so the variable is quantitative, not categorical. Within quantitative, the values are counts (whole numbers): you cannot sell 22.4 video games, the possible values form a countable set with gaps, and the variable cannot take on values between consecutive integers — so it is discrete (EK UNC-1.F.1). Choice B (quantitative and continuous) is the most common wrong answer: students may think "it's numbers so it must be continuous," but continuous requires that values fill every point in an interval (EK UNC-1.F.2), which counts do not do. Push students to name the two decisions separately — first categorical-vs-quantitative, then discrete-vs-continuous — and justify each using the framework definitions.
