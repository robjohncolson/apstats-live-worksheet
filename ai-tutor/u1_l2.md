**[Item 1 of 3] — U1-L2-Q01**

The following table shows data for the 8 longest roller coasters in the world as of 2015. Which of the following variables is categorical?

| Length (feet) | Type | Speed (miles per hour) | Height (feet) | Drop (feet) | Continent |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 8,133 | Steel | 95 | 318 | 310 | Asia |
| 7,442 | Steel | 50 | 107 | 102 | Europe |
| 7,359 | Wood | 65 | 110 | 135 | North America |
| 6,709 | Steel | 81 | 259 | 230 | Asia |
| 6,602 | Steel | 95 | 325 | 320 | North America |
| 6,595 | Steel | 93 | 310 | 300 | North America |
| 6,562 | Steel | 149 | 171 | 168 | Asia |
| 6,442 | Wood | 67 | 163 | 154 | North America |

(A) Length
(B) Type
(C) Speed
(D) Height
(E) Drop

KEY: B

WHY (for the tutor's eyes; do not reveal verbatim): This item tests VAR-1.C (Classify types of variables), specifically EK VAR-1.C.1 (categorical = category names or group labels) vs. EK VAR-1.C.2 (quantitative = numerical values for a measured or counted quantity). "Type" (Steel/Wood) takes on group labels — no arithmetic operation on those labels is meaningful — making it categorical. The strongest distractor is (A) Length: students may see it as a label because it has a comma-formatted number, but length is a measured quantity where arithmetic (average, difference) is meaningful, so it is quantitative. Push students who pick any of A/C/D/E to articulate: "Can you add or average those values in a meaningful way?" That question exposes the core distinction under EK VAR-1.C.1 and VAR-1.C.2.

**[Item 2 of 3] — U1-L2-Q02**

Which of the following questions about cars in a school parking lot will allow for the collection of a set of categorical data?

(A) How many blue cars are in the lot?
(B) What are the gas mileages, in miles per gallon, of the cars in the lot?
(C) What are the weights, in pounds, of the cars in the lot?
(D) What is the number of cars in the lot with out-of-state license plates?
(E) What are the colors of the cars in the lot?

KEY: E

WHY (for the tutor's eyes; do not reveal verbatim): This item tests LO VAR-1.C (classify types of variables) via EK VAR-1.C.1 — a categorical variable takes on values that are category names or group labels. Color (red, blue, white, etc.) is a group label with no numerical meaning, so (E) is correct. The strongest distractors are (A) and (D): both involve counting cars, and students often confuse "a count that results from categorizing" with "a categorical variable itself." The key distinction is that the question asks what variable is being collected — color is the variable (categorical), while "how many blue cars" produces a count of one category, yielding a single number (a summary statistic), not a set of categorical data values. Point students who choose A or D back to EK VAR-1.C.1: ask them what value gets recorded for each individual car.

**[Item 3 of 3] — U1-L2-Q03**

Data were collected on 100 United States coins minted in 2018. Which of the following represents a quantitative variable for the data collected?

(A) The type of metal used in the coin
(B) The value of the coin
(C) The color of the coin
(D) The person depicted on the face of the coin
(E) The location where the coin was minted

KEY: B

WHY (for the tutor's eyes; do not reveal verbatim): This item tests LO VAR-1.C (classify types of variables), targeting EK VAR-1.C.2 — a quantitative variable takes on numerical values for a measured or counted quantity. The value of a coin (1 cent, 5 cents, 10 cents, 25 cents, etc.) is a numerical amount for which arithmetic is meaningful (you can sum or average coin values), making it quantitative. The strongest distractors are (A) type of metal and (D) person depicted, which are clearly categorical labels. Some students may hesitate on (E) location (mint city), which sounds like it could be a number, but it is a place name — a group label under EK VAR-1.C.1. If a student wavers between B and E, ask: "What actual value gets recorded for each coin — a number that measures something, or a name/label?"
