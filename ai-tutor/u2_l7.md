**[MCQ] U2-L7-Q01**

A researcher collected data on the age, in years, and the growth of sea turtles. The following graph is a residual plot of the regression of growth versus age. Does the residual plot support the appropriateness of a linear model?

[This item shows a chart in the quiz.]

Tutor-only chart description (do not share this description with the student; prompt them to describe what they see themselves): Scatter plot titled with x-axis "Age in Years" (range 0–6, tick interval 1) and y-axis "Residuals" (range −0.6 to 0.6, tick interval 0.2), with a horizontal reference line at y = 0. The 26 plotted points form a U-shaped pattern: residuals start positive near age 0.8–1.6 (roughly +0.0 to +0.5), dip to negative values around ages 1.8–3.2 (roughly −0.35 to −0.15), then rise back to positive values around ages 4.4–5.0 (roughly +0.30 to +0.37), with a few near-zero points scattered in between. Do not compute or confirm whether the pattern is random or curved for the student — ask them to describe the pattern they observe.

(A) Yes, because there is a clear pattern displayed in the residual plot.
(B) Yes, because about half the residuals are positive and the other half are negative.
(C) Yes, because as age increases, the residuals increase.
(D) No, because the points appear to be randomly distributed.
(E) No, because the graph displays a U-shaped pattern.

KEY: E

WHY (for tutor's eyes; do not reveal verbatim): This item tests LO DAT-1.F / EK DAT-1.F.1 and EK DAT-1.F.2. A U-shaped pattern in a residual plot is a clear, non-random systematic pattern — evidence that the linear model is not appropriate for these data, because a curved (non-linear) relationship exists between age and growth. Choice (A) is wrong because it reaches the right conclusion ("clear pattern") but draws the wrong inference — a clear pattern means the linear model is NOT appropriate, not that it is. Choice (B) confuses roughly equal numbers of positive and negative residuals with random scatter; "about half positive, half negative" is not sufficient for randomness if they follow a curved sequence. Choice (C) describes a positive trend in residuals, which is incorrect — the plot shows a U-shape, not a monotone increase. Choice (D) is opposite the correct reading; the student must articulate that the U-shape is a pattern, not random scatter (EK DAT-1.F.1). Ask the student: "What does EK DAT-1.F.1 say you need to see in a residual plot if the linear model IS appropriate? Does that match what you see here?"

**[MCQ] U2-L7-Q02**

The following is a residual plot for a linear regression of y versus x. What is indicated by the plot?

[This item shows a chart in the quiz.]

Tutor-only chart description (do not share this description with the student; prompt them to describe what they see themselves): Scatter plot with x-axis "x" (range 0–20, tick interval 5) and y-axis "Residual" (range −5.0 to 7.5, tick interval 2.5), with a horizontal reference line at y = 0. The 14 plotted points follow a curved pattern: residuals are negative for low x values (x = 1 through 5, ranging from −1.0 to −5.0), then rise through zero around x = 7, become positive and peak around x = 11 (up to +6.5), then fall back to negative values for high x values (x = 15 through 20, ranging from −1.0 to −5.0). The overall shape is an inverted U (arch). Do not compute or confirm whether this indicates linear or non-linear for the student — ask them to describe what they see in the pattern of residuals.

(A) A linear model is appropriate.
(B) A linear model is not appropriate.
(C) Variability in y is constant for all values x.
(D) At least one point is influential with respect to the regression.
(E) At least one point is an outlier with respect to the regression.

KEY: B

WHY (for tutor's eyes; do not reveal verbatim): This item tests LO DAT-1.F / EK DAT-1.F.1 and EK DAT-1.F.2. The systematic curved (inverted-U / arch) pattern in the residuals shows that the residuals are not randomly scattered around zero — they follow a predictable non-linear structure. By EK DAT-1.F.1, apparent randomness is required for the linear model to be appropriate; the absence of randomness (the curved pattern) is evidence that the linear model is not appropriate. Choice (A) is the direct misconception: some students see points on both sides of the zero line and conclude the model is fine, missing the systematic curvature. Choice (C) addresses constant variance (homoscedasticity), a different concern — the issue here is the curved pattern, not whether spread changes with x. Choices (D) and (E) are distractors about influential points and outliers (LO DAT-1.I, from Topic 2.9), not about model appropriateness from a residual plot. Ask the student: "According to EK DAT-1.F.1, what does apparent randomness in a residual plot tell us? Is what you see in this plot random or patterned?"

**[MCQ] U2-L7-Q03**

An engineer believes that there is a linear relationship between the thickness of an air filter and the amount of particulate matter that gets through the filter; that is, less pollution should get through thicker filters. The engineer tests many filters of different thickness and fits a linear model. If a linear model is appropriate, what should be apparent in the residual plot?

(A) There should be a positive, linear association in the residual plot.
(B) There should be a negative, linear association in the residual plot.
(C) All of the points must have residuals of 0.
(D) There should be no pattern in the residual plot.
(E) The residuals should have a small amount of variability for low values of the predictor variable and larger amounts of variability for high values of the predictor variable.

KEY: D

WHY (for tutor's eyes; do not reveal verbatim): This item tests LO DAT-1.F / EK DAT-1.F.1 directly. When a linear model is appropriate, residuals should be randomly scattered around zero with no discernible pattern — that is what EK DAT-1.F.1 states. Choice (A) and (B) are misconceptions that confuse the direction of the original relationship (negative, since thicker filters let through less pollution) with what the residual plot should look like; if the linear model fits well, residuals should show no systematic direction at all. Choice (C) is a perfection fallacy — real data always has some variation, so residuals of exactly 0 would require a perfect fit, which is not the standard for model appropriateness. Choice (E) describes non-constant variance (heteroscedasticity), which is a separate concern from whether the form is linear. The key Socratic move: ask the student what EK DAT-1.F.1 says randomness in a residual plot means, and then ask them which answer choice describes that condition.
