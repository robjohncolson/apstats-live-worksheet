**[MCQ] U6-L7-Q01**
Which of the following gives the probability of making a Type I error?

(A) The sample size
(B) The power
(C) The significance level
(D) The standard error
(E) The p-value

KEY: C

WHY (for the tutor's eyes; never reveal verbatim): The significance level α chosen for the test defines the probability of making a Type I error (EK UNC-5.B.1). A Type I error occurs when we reject a true null hypothesis, and α is set as the maximum acceptable probability for this error. Top distractor is E (the p-value): students confuse the p-value — the probability of the observed data given H₀ — with α, the pre-set decision threshold. The p-value is compared to α to make a decision; it is not the probability of error.

**[MCQ] U6-L7-Q02**
Consider the results of a hypothesis test, which indicate there is not enough evidence to reject the null hypothesis. Which of the following statements about error is correct?

(A) A Type I error could have been made, but not a Type II error.
(B) A Type II error could have been made, but not a Type I error.
(C) Both types of error could have been made, but the probability of a Type I error is greater than the probability of a Type II error.
(D) Both types of error could have been made, but the probability of a Type I error is less than the probability of a Type II error.
(E) The type of error that could have been made is not possible to determine without knowing the statement of the null hypothesis.

KEY: B

WHY (for the tutor's eyes; never reveal verbatim): A Type II error occurs when the null hypothesis is false but has not been rejected (EK UNC-5.A.2). Since the test resulted in a failure to reject H₀, only a Type II error is possible — we did not reject, so we cannot have made the mistake of rejecting something true (Type I). Top distractor is A: students mix up which error goes with which decision. A Type I error requires a rejection; if there was no rejection, there can be no Type I error.

**[MCQ] U6-L7-Q03**
At a manufacturing company for medical supplies, machines produce parts used in highly specialized lasers. Company researchers are testing a new machine designed to improve the precision of the parts. The null hypothesis is that the new machine does not improve the precision. For the researchers, the more consequential error would be that the new machine actually improves the precision, but the test does not detect the improvement. Which of the following should the researchers do to avoid the more consequential error?

(A) Increase the significance level to increase the probability of a Type I error.
(B) Increase the significance level to decrease the probability of a Type I error.
(C) Decrease the significance level to increase the probability of a Type I error.
(D) Decrease the significance level to decrease the probability of a Type I error.
(E) Decrease the significance level to decrease the standard error.

KEY: A

WHY (for the tutor's eyes; never reveal verbatim): The described error — the machine is effective but the test fails to detect it — is a Type II error (EK UNC-5.A.2). To decrease the probability of a Type II error, the researchers increase α (the significance level), which makes the test more willing to reject H₀, thereby increasing power (EK UNC-5.C.1). There is a trade-off: raising α increases the probability of a Type I error (EK UNC-5.D.2). Distractors B, C, D are traps that misstate the direction of the relationship between α and Type I/II error probabilities.

**[MCQ] U6-L7-Q04**
Machines at a bottling plant are set to fill bottles to 12 ounces. The quality control officer at the plant periodically tests the machines to be sure that the bottles are filled to an appropriate amount. The null hypothesis of the test is that the mean is at least 12 ounces. The alternative hypothesis is that the mean is less than 12 ounces. Which of the following describes a Type I error that could result from the test?

(A) The test does not provide convincing evidence that the mean is less than 12 ounces, but the actual mean is at least 12 ounces.
(B) The test does not provide convincing evidence that the mean is less than 12 ounces, but the actual mean is less than 12 ounces.
(C) The test does not provide convincing evidence that the mean is less than 12 ounces, but the actual mean is 12 ounces.
(D) The test provides convincing evidence that the mean is less than 12 ounces, but the actual mean is at least 12 ounces.
(E) The test provides convincing evidence that the mean is less than 12 ounces, but the actual mean is 11 ounces.

KEY: D

WHY (for the tutor's eyes; never reveal verbatim): A Type I error is rejecting a true null hypothesis — a false positive (EK UNC-5.A.1). Here H₀ is that the mean is at least 12 oz. A Type I error means: the test rejects H₀ (finds convincing evidence the mean is less than 12 oz), but H₀ is actually true (the mean is at least 12 oz). That is exactly option D. Top distractor is E: option E looks similar but the "actual mean is 11 oz" makes H₀ false, so rejecting it would be a correct decision, not an error. Students must apply the error-table logic in context (LO UNC-5.A, LO UNC-5.D).

**[MCQ] U6-L7-Q05**
At a large company, employees can take a course to become certified to perform certain tasks. There is an exam at the end of the course that needs to be passed for certification. The current pass rate is 0.7, but a new program is being tested to help increase the pass rate. The null hypothesis of the test is that the pass rate for the new program is 0.7. The alternative is that the pass rate for the new program is greater than 0.7. Which of the following describes a Type II error that could result from the test?

(A) The test does not provide convincing evidence that the pass rate is greater than 0.7, but the actual pass rate is 0.8.
(B) The test does not provide convincing evidence that the pass rate is greater than 0.7, but the actual pass rate is 0.7.
(C) The test does not provide convincing evidence that the pass rate is greater than 0.7, but the actual pass rate is 0.6.
(D) The test provides convincing evidence that the pass rate is greater than 0.7, but the actual pass rate is 0.8.
(E) The test provides convincing evidence that the pass rate is greater than 0.7, but the actual pass rate is 0.6.

KEY: A

WHY (for the tutor's eyes; never reveal verbatim): A Type II error is failing to reject a false null hypothesis (EK UNC-5.A.2). Here H₀ is that the pass rate = 0.7. A Type II error means: the test fails to reject H₀ (no convincing evidence the rate is greater than 0.7), but H₀ is actually false (the true rate is 0.8, so Hₐ is true). That is exactly option A. Distractor B has the actual rate at 0.7, so H₀ is true — failing to reject it would be a correct decision, not an error. Students must recognize that a Type II error requires H₀ to be false and the test to have missed it (LO UNC-5.A).

**[MCQ] U6-L7-Q06**
Consider a hypothesis test in which the significance level is α = 0.05 and the power of the test is 0.65. What is the probability of making a Type II error?

(A) 0.95
(B) 0.65
(C) 0.60
(D) 0.35
(E) 0.05

KEY: D

WHY (for the tutor's eyes; never reveal verbatim): The probability of a Type II error = 1 − power (EK UNC-5.B.3). With power = 0.65, P(Type II error) = 1 − 0.65 = 0.35. Power is the probability of correctly rejecting a false null hypothesis, so 1 − power gives the probability of failing to reject a false null. Top distractor is E (0.05): students may confuse α with P(Type II error). α = 0.05 is the probability of a Type I error, not Type II (EK UNC-5.B.1). Also watch for A (0.95 = 1 − α), which conflates the complement of α with the Type II error probability.

Medical researchers are testing a new surgical procedure designed to minimize the side effects of surgery. The null hypothesis is that the procedure is not effective in minimizing side effects. For the researchers, the more consequential error would be that the procedure actually is effective in minimizing the side effects, but the test does not detect the effectiveness of the procedure. Which of the following should the researchers do to avoid the more consequential error?

KEY: A

**[MCQ] U6-L7-Q10**
If all else is constant, which of the following would result in a decrease of the probability of a Type II error?

(A) The true parameter is closer to the null.
(B) The sample size is increased.
(C) The significance level is decreased.
(D) The standard error is increased.
(E) Type II error cannot be decreased, only increased.

KEY: B

WHY (for the tutor's eyes; never reveal verbatim): Increasing sample size decreases the standard error of the sampling distribution (σ/√n), making it easier to detect a true difference between the parameter and the null value (EK UNC-5.C.1.i). Lower variability → higher power → lower P(Type II error). Distractor A is the opposite: a true parameter closer to the null makes differences harder to detect, increasing P(Type II error) (EK UNC-5.C.1.iv, reversed). Distractor C is also the opposite: decreasing α makes the test more stringent, lowering power and increasing P(Type II error).

**[MCQ] U6-L7-Q13**
Which of the following is the best interpretation of the power of a significance test?

(A) Power is the probability of detecting an effect if no effect exists.
(B) Power is the probability of detecting an effect if an effect exists.
(C) Power is the probability of detecting an effect whether or not an effect exists.
(D) Power is the probability of not detecting an effect if no effect exists.
(E) Power is the probability of not detecting an effect if an effect exists.

KEY: B

WHY (for the tutor's eyes; never reveal verbatim): Power is the probability that the test will correctly reject a false null hypothesis — in plain language, the probability of detecting an effect that truly exists (EK UNC-5.B.2). Power = 1 − P(Type II error). Distractor A describes a Type I error (detecting an effect when none exists). Distractor E describes a Type II error (not detecting an effect that does exist). Students often confuse power with the complement of α or conflate it with p-value; grounding in EK UNC-5.B.2 and the error table (LO UNC-5.A) clarifies all five options.
