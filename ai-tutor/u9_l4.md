**[Item 1 of 9] — [MCQ] U9-L4-Q01**

A seafood festival organizer is interested in whether there is a relationship between the number of ingredients in the clam chowders that are entered in the festival's clam chowder contest and the ratings given to the chowders by the judges. The organizer requires each of the twelve restaurants in the competition to list all of its chowder's ingredients and requires each judge who tastes the clam chowders to rate each chowder from one through ten on a note card. The organizer then randomly selects twenty-five note cards. Assuming that all conditions for inference are met, which of the following significance tests should be used to investigate whether having more ingredients in the chowders is associated with a reduction in the ratings given to the chowders by the judges?

(A) A chi-square test of independence
(B) A two-sample t-test for a difference between means
(C) A two-sample z-test for a difference between proportions
(D) A linear regression t-test for slope
(E) A matched pairs t-test for a mean difference

KEY: D

WHY (for the tutor's eyes; never reveal): The organizer is investigating whether two quantitative variables — number of ingredients (quantitative) and rating (quantitative) — have a linear relationship, specifically whether more ingredients predicts lower ratings. This calls for a linear regression t-test for slope (EK VAR-7.J.1). The top distractors are (A) chi-square, which applies to categorical variables, and (B) two-sample t, which compares means of two groups rather than testing a linear relationship between two continuous measurements. The "reduction in ratings" language signals a directional hypothesis about slope, which is the domain of the regression t-test.

**[Item 3 of 9] — [MCQ] U9-L4-Q03**

A doctor recorded the number of miles walked each day by patients over age 60 and the number of doctor visits in a year for 40 patients. The resulting data were used to conduct a hypothesis test to determine whether there is a linear relationship between the number of miles walked and the number of doctor visits. What are the correct hypotheses for the test?

(A) H₀: b₁ = 0, Hₐ: b₁ ≠ 0
(B) H₀: β₁ = 0, Hₐ: β₁ > 0
(C) H₀: β₁ = 0, Hₐ: β₁ < 0
(D) H₀: β₁ ≠ 0, Hₐ: β₁ = 0
(E) H₀: β₁ = 0, Hₐ: β₁ ≠ 0

KEY: E

WHY (for the tutor's eyes; never reveal): The question asks whether there is a linear relationship — no direction specified — so the alternative is two-sided (β₁ ≠ 0). The hypotheses must use β₁, the population slope parameter, not b₁, the sample statistic (EK VAR-7.K.1). Choice (A) fails because it uses b₁ (sample statistic) instead of β₁ (population parameter). Choices (B) and (C) have the correct parameter but impose a one-sided direction not supported by the research question. Choice (D) reverses null and alternative, which is never correct.

**[Item 6 of 9] — [MCQ] U9-L4-Q06**

Which of the following would be an indication that the normality condition has been met for a t-test for the slope of a regression model?

I. A residual plot with no apparent pattern in the residuals
II. A histogram of the residuals that is centered at 0, unimodal, and symmetric
III. A dotplot of the residuals that is centered at 0 and strongly skewed to the left with outliers

(A) I only
(B) II only
(C) I and II only
(D) II and III only
(E) I, II, and III

KEY: B

WHY (for the tutor's eyes; never reveal): The normality condition (EK VAR-7.L.1d) requires that the distribution of residuals be approximately normally distributed — checked via graphical representations of the residuals (histograms, dotplots, normal probability plots) that are centered at 0, free from strong skewness, and free from outliers. Statement II describes a histogram that is centered at 0, unimodal, and symmetric — this supports normality. Statement III describes a distribution that is strongly skewed with outliers — this violates the normality condition. Statement I describes a residual plot (residuals vs. x), which is used to check linearity (EK VAR-7.L.1a) and constant variance (EK VAR-7.L.1b), NOT normality. The common error is to think any "good-looking" residual plot confirms all conditions; students must distinguish which plot type checks which condition.
