\begin{callout}{\IconBook\ READING HISTOGRAMS (keep on the page)}{calloutgreen}
A histogram groups observations into intervals; each bar gives the count in its interval. Values at a boundary go in the interval that starts there. Changing interval widths changes the appearance, not the observations. Narrow intervals can reveal separated groups and empty intervals; wide intervals summarize broad counts. A histogram does not show each exact value or attach a group label to each observation.
\end{callout}
