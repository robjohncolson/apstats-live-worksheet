\begin{callout}{\IconBook\ EXPECTED COUNTS UNDER NO ASSOCIATION (keep on the page)}{calloutgreen}
Expected counts describe the table under no relationship between the variables.
For an interior cell, $E=(\text{row total})(\text{column total})/(\text{table total})$.
Expected counts keep the same row and column totals; they need not be whole numbers.
For this problem, use the course's conservative chi-square check: every expected count must be
greater than 5. This check concerns expected counts, not observed counts. If it fails, gather more
random data and recheck; a larger sample does not guarantee that every new expected count will pass.
\end{callout}
