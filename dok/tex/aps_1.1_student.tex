\begin{callout}{\IconBook\ USE DATA IN CONTEXT (keep on the page)}{calloutgreen}
A variable is a characteristic recorded for each individual. Variation means the values differ. A threshold is a cutoff used to decide whether action is needed. $\text{Percent}=100\times\dfrac{\text{count meeting the condition}}{\text{total count}}$. When observations are removed, count the remaining observations and use the remaining total. Interpret the result in the original context.
\end{callout}
