\begin{callout}{\IconBook\ VARIABLES (keep on the page)}{calloutgreen}
An \textbf{individual} is a person or thing the data describe. A \textbf{variable} is a characteristic that can change between individuals. An identifier only names an individual. \textbf{Categorical} values are category names or group labels, even when written with digits. \textbf{Quantitative} values are numbers for a measured or counted quantity. State units for measurements. Before averaging, ask what quantity the values measure or count.
\end{callout}
