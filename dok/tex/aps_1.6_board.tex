\begin{firsttakebox}{FIRST TAKE (5 min, on your sheet)}
Whose description do you trust more, Ana's or Ben's? One sentence. No wrong answers yet.
\end{firsttakebox}

\begin{description}[leftmargin=1.15in, labelwidth=1in, itemsep=2pt, topsep=2pt]
  \item[\dokbadge{1}~(a)] Name the shape of the histogram and state which interval contains the median commute time.
  \item[\dokbadge{2}~(b)] Describe the distribution of commute times in context. Address shape, center, variability, and any unusual features, with units.
  \item[\dokbadge{3}~(c)] Whose description could a reader trust when choosing a summary statistic? Cite two specific features of the graph that settle it. Then state which measure of center you would report for these data and why.
\end{description}
