\focusbanner{TODAY'S PROBLEM --- annotated}

Suppose a hospital randomly samples 12 of its 180 billing specialists. Each does the same task on the current computer screen and, one week later, on a redesigned screen. Everyone uses the current screen first; there is no comparison group. Let $d=\text{current}-\text{redesigned}$ time in seconds. The plot shows the differences; $\bar d=2.000$, $s_d=1.6514$, and the 95\% critical value is $t^*=2.201$.\par\smallskip \textbf{Priya:} ``Use one sample of paired differences. Doing the tasks in a fixed order limits a cause-and-effect claim.''\par \textbf{Mateo:} ``Two columns require two independent samples. A positive interval proves the redesign caused faster work.''\par

\dokbadge{1}~\textbf{(a)} How many paired differences are there, and what does a positive difference mean?\par
\answer{There are 12 paired differences. A positive current-minus-redesigned difference means the later task took less time.}

\dokbadge{2}~\textbf{(b)} Use the supplied summaries to calculate the 95\% interval $\bar d\pm t^*(s_d/\sqrt n)$. Show one calculation.\par
\answer{$2.000\pm2.201(1.6514/\sqrt{12})=2.000\pm1.0493=(0.9507,3.0493)$ seconds (small rounding differences accepted).}

\dokbadge{3}~\textbf{(c)} In 3--4 sentences, choose an analysis and justify it from the linked measurements. Interpret the interval for the 180 specialists, then explain why practice or the fixed order limits a causal claim.\par
\answer{Priya is better supported because each specialist supplies two linked measurements, so the 12 differences form one sample. Treating the columns as independent loses that link and changes the standard error. We are 95\% confident the mean current-minus-redesigned time for the 180 specialists under this sequence is about 0.95 to 3.05 seconds. Because the current screen always came first and there was no comparison group, practice or time could explain the improvement; the redesign alone is not shown to cause it.}
