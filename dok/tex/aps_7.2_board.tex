\daybanner{Unit 4 \textperiodcentered\ Topic 4.2 \textperiodcentered\ TODAY'S PROBLEM}{Two Interfaces, Twelve Specialists}

\noindent\begin{minipage}[t]{0.57\linewidth}
\vspace{0pt}
Suppose a hospital randomly samples 12 of its 180 billing specialists. Each does the same task on the current computer screen and, one week later, on a redesigned screen. Everyone uses the current screen first; there is no comparison group. Let $d=\text{current}-\text{redesigned}$ time in seconds. The plot shows the differences; $\bar d=2.000$, $s_d=1.6514$, and the 95\% critical value is $t^*=2.201$.\par\smallskip \textbf{Priya:} ``Use one sample of paired differences. Doing the tasks in a fixed order limits a cause-and-effect claim.''\par \textbf{Mateo:} ``Two columns require two independent samples. A positive interval proves the redesign caused faster work.''\par
\end{minipage}\hfill
