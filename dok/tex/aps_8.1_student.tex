\begin{callout}{\IconBook\ BUILD DISCREPANCY FROM THE NULL MODEL (keep on the page)}{calloutgreen}
For model probability $p_i$ and sample size $n$, category $i$ has expected count $np_i$.
Measure total relative discrepancy with $\chi^2=\sum (O-E)^2/E$; for $k$ model categories,
$df=k-1$. A valid null simulation generates a new sample of size $n$ using the claimed
probabilities, recomputes $\chi^2$, and counts simulated values at least as large as observed.
Merely rearranging fixed observed labels cannot show sample-to-sample count variation.
\end{callout}
