\begin{callout}{\IconBook\ ERROR PROBABILITIES TRADE OFF (keep on the page)}{calloutgreen}
A Type I error rejects a true $H_0$, and its probability is $\alpha$. A Type II error fails to reject a false
$H_0$; $\beta=1-\text{power}$. With sample size fixed, increasing $\alpha$ generally raises power and lowers
$\beta$, but it also raises the false-positive risk. Increasing sample size can raise power while keeping the
chosen $\alpha$ fixed. Choose a plan by naming the real consequence of each error.
\end{callout}
