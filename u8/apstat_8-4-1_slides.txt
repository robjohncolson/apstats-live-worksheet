[02:01] — Concept: Expected Counts Calculation
The definition of expected counts is provided.

Heading: "Expected Counts"

Rule: "Expected counts in a two-way table are calculated assuming there is no relationship between the two categorical variables."

[02:17] — Calculating Totals
The previous table is expanded to include totals.

Step 1 (02:22): Find row totals (Public: 429, Private: 37, Home: 68).

Step 2 (02:31): Find column totals (2019: 320, 2020: 214).

Step 3 (02:40): Find the table total (534).

[02:54] — Deriving the Expected Count Formula
The instructor demonstrates the logic behind the formula using the "Public" row.

Proportion calculation: "Overall proportion that attend public school = 429 / 534 = 0.8034".

Application to 2019 (03:26): "80.34% of the 2019 sample should attend public school, or (0.8034)(320) = 257.1".

The combined calculation (03:51): "expected count (public, 2019) = (429 / 534)(320) = 257.1".

[04:28] — Calculating Expected Counts for the Table
The formula is applied to populate the table. The expected counts are written in blue parentheses next to observed values.

Cell 1 (04:38): Expected count (Private, 2019) = (37)(320) / 534 = 22.2.

Shortcut Method (05:29): For the last cell in a column, subtract known expected counts from the column total. Expected count (Home, 2019) = 320 - (257.1 + 22.2) = 40.7.

Row Shortcut (05:45): Expected count (Public, 2020) = 429 - 257.1 = 171.9.

Completion (06:00): Remaining cells are calculated using subtraction (14.8 and 27.3). A key "(expected counts)" is added.
