    <ul style='margin: 8px 0 0 0; padding-left: 20px;'>
        <li>Interpret a confidence interval for the slope of a population regression line in context.</li>
        <li>Interpret the meaning of a confidence level for slope using repeated random sampling.</li>
        <li>Use a confidence interval to decide whether data provide convincing evidence for a claim about slope.</li>
        <li>Determine how including or excluding a claimed slope value affects the conclusion of an inference.</li>
        <li>Construct, calculate, and interpret a confidence interval for slope from regression output and use it to evaluate a real claim.</li>
    </ul>
    <strong style='margin-top: 10px; display: block;'>Essential Knowledge:</strong>
    <ul style='margin: 8px 0 0 0; padding-left: 20px;'>
        <li>A confidence interval for slope is interpreted like any other confidence interval, but the parameter is the slope of a population regression line.</li>
        <li>The confidence level describes the long-run success rate of intervals from repeated random samples of the same size.</li>
        <li>If &beta; = 0, the population regression line is horizontal, so there is no linear relationship between x and y.</li>
        <li>If a confidence interval for slope contains 0, there is not convincing evidence of a linear relationship.</li>
        <li>If all values in the interval are positive, there is convincing evidence of a positive linear relationship; if all are negative, there is convincing evidence of a negative linear relationship.</li>
        <li>Claims are justified by checking whether the interval contains values that are consistent with the claim.</li>
        <li>In the real estate example, b = -2.158, SE<sub>b</sub> = 0.149, t* = 2.101, and the 95% confidence interval is -2.471 to -1.845.</li>
        <li>Because -2 is inside that interval, the data do not contradict the agent's belief that price decreases about $2,000 per mile.</li>
    </ul>

<div class='vocab-box'>
    <h3>Key Vocabulary</h3>
    <table class='vocab-table'>
        <tr><td>Confidence Interval for Slope</td><td>An interval estimate for the true slope &beta; of a population regression line.</td></tr>
        <tr><td>Interpretation in Context</td><td>Stating what the interval says about the population slope for the real variables being studied.</td></tr>
        <tr><td>Confidence Level</td><td>The percent of intervals from many repeated random samples that would capture the true parameter.</td></tr>
        <tr><td>Plausible Value</td><td>A parameter value that is contained in the confidence interval and is therefore consistent with the data.</td></tr>
        <tr><td>&beta; = 0</td><td>A slope of zero, which means the population regression line is horizontal.</td></tr>
        <tr><td>Linear Relationship</td><td>A relationship in which the mean response changes at a constant rate as x changes.</td></tr>
        <tr><td>Convincing Evidence</td><td>Support from the interval that a claim about the slope is reasonable based on the sample data.</td></tr>
        <tr><td>Consistent with the Claim</td><td>A value in the interval that matches what the claim says could be true.</td></tr>
        <tr><td>Contradict the Claim</td><td>To show the claim is not plausible because the claimed value is outside the interval.</td></tr>
        <tr><td>One-Sample t Interval for &beta;</td><td>The procedure used to estimate the slope of a population regression line when population quantities are unknown.</td></tr>
        <tr><td>Point Estimate</td><td>The sample slope b used as the center of the confidence interval.</td></tr>
        <tr><td>Margin of Error</td><td>The amount added to and subtracted from the point estimate to form the interval.</td></tr>
        <tr><td>Critical Value</td><td>The t-multiplier based on the confidence level and degrees of freedom.</td></tr>
    </table>

        function checkAnswer(blank) {
            const userAnswer = normalize(blank.value);
            const acceptedRaw = blank.dataset.answer || '';
            const accepted = acceptedRaw.split('|').map(normalize);

            blank.classList.remove('correct', 'partial', 'incorrect', 'revealed');

                return 'partial';

                        result.suggestion = null;
                    }

                    const matchedCount = (result.matched || []).length;
                    const missingCount = (result.missing || []).length;
                    const totalElements = matchedCount + missingCount;
                    const hitRate = totalElements > 0 ? matchedCount / totalElements : 0;

                    if (result.score === 'P' && hitRate >= 0.3 && missingCount > 0) {
                        btn.textContent = '\u2728 Polishing...';
                        try {
                            const enriched = await fetchEnrichedAnswer(id, answer, result.missing);

                    }
                    // --- End Enriched Pass ---

                    showFeedback(id, result);

                    console.error('Grading error:', err);
                    showFeedback(id, { score: 'I', feedback: 'Error grading response. Please try again.' });
