# Phase 99A — Rewrite font-decoder.mjs to 1bpp 16-wide × 14-tall

## Context

Phase 98A found the TI-84 CE large font at ROM 0x0040ee, 28 bytes/glyph, idx = char_code - 0x20. The commit 679c286 of `TI-84_Plus_CE/font-decoder.mjs` assumed 2bpp 8-wide. **That interpretation is WRONG.** Manual byte dumps of 'H'/'T'/'X'/'P'/'0' prove the real format is **1 bit per pixel, 2 bytes per row, 14 rows, 16 pixels wide** (effective glyph width ~13 px; cols 13-15 are blank padding).

Byte-level evidence at base 0x0040ee, stride 28:
- 'H' (0x48, idx 40): `##.........##...` × 6 rows, crossbar `#####...#####...`, then `##.........##...` × 6 more = classic H shape with two vertical strokes at cols 0-1 and 11-12 and a crossbar at rows 6-8.
- 'T' (0x54): `#####...#####...` × 2 top rows, then `....#...#.......` × 12 = classic T.
- 'X' (0x58): clean diagonals.
- 'P' (0x50): top loop + vertical stroke.
- '0' (0x30): oval outline.

The layout per 28-byte glyph entry: 14 rows × 2 bytes per row. For row R, `byte0 = mem[base + R*2]` holds pixels for cols 0-7 (bit 7 = col 0, bit 0 = col 7). `byte1 = mem[base + R*2 + 1]` holds pixels for cols 8-15 (bit 7 = col 8, bit 0 = col 15). Each bit: 1 = foreground pixel, 0 = background.

### Specific changes

1. **GLYPH_WIDTH = 16** (change the export constant).
2. **decodeGlyph**: for each row 0..13, read `b0 = romBytes[off + row*2]` and `b1 = romBytes[off + row*2 + 1]`. For col 0..7: `bitmap[row*16 + col] = (b0 >> (7 - col)) & 1`. For col 8..15: `bitmap[row*16 + col] = (b1 >> (15 - col)) & 1`.
3. **extractCell**: widen to 16 cols (keep the same bounds/sentinel/inverse logic).
4. `matchCell`, `hamming`, `decodeTextStrip` should adapt automatically from `GLYPH_WIDTH`. Verify the `maxDist = 20` default still works — you may need to bump it proportionally (try 30 or 40 since the cell is now 2x wider); pick a value that lets the self-test still recognize decoded cells reliably.
5. The inverse-video mode added by Phase 99A prep is already in `extractCell`. Keep it.
6. Update the header comment block to reflect the corrected format (remove "2 bits per pixel (anti-aliased)" line).
