## Deliverables (all files in TI-84_Plus_CE/)

### 1. `probe-phase77d-mode-var-readers.mjs`
Node script that:
- Uses the exact OS-init prelude from `probe-phase64-0a1cac-novel-callers.mjs`: full boot from 0x000000, OS init at 0x08c331, SetTextFgColor at 0x0802b2, then direct entry probe.
- For each candidate entry: 0x0a2812, 0x0a281a, 0x0a29a8, 0x0a654e, runs MULTIPLE register variants:
  - Variant 1: HL=0, A=0, IY=0xD00080
  - Variant 2: HL=0x0a0452 (prgm token name), A=0x4C, IY=0xD00080
  - Variant 3: HL=0x0a0467 (Normal token name), A=0x4F, IY=0xD00080
  - Variant 4: HL=0, A=0, IY=0xD00080, but first write token-indicative bytes to 0xD00085=0x4F, 0xD00092=0x52 (suggesting Normal+Float mode)
- For each variant × entry combination, run maxSteps=15000 and capture:
  - VRAM writes (diff from 0xAAAA sentinel)
  - fg count (non-0xFFFF non-sentinel) and bg count (0xFFFF)
  - Bounding box (minRow, maxRow, minCol, maxCol of non-sentinel pixels)
  - First 10 blocks executed
  - ASCII-art decode of the bbox region if drawn > 300 (stride-1 decode, '#' for fg, '.' for bg, ' ' for sentinel)
