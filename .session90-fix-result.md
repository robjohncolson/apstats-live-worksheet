## Fix 4 (chart instance leak cleanup)
- `study_guide_diagnostic.html`: Before the single `ui.active.innerHTML = ''` call in `renderActiveProbe()`, added cleanup block:
  ```js
  if (window.chartInstances && ui.active) {
    const oldCanvases = ui.active.querySelectorAll('canvas[id^="sg-chart-"]');
    oldCanvases.forEach(c => {
      const inst = window.chartInstances[c.id];
      if (inst && typeof inst.destroy === 'function') {
        try { inst.destroy(); } catch (_) { /* ignore */ }
        delete window.chartInstances[c.id];
      }
    });
  }
  ```
  Wrapped in defensive guard so it no-ops when `chartInstances` is absent (e.g., before any chart question is rendered).
