AP Statistics Unit 7 Inference for Means

Topic 7.4: Setting Up a Test for a Population Mean

Null and Alternative Hypotheses, Procedure, and Conditions
Video Follow-Along Worksheet
Learning Objectives:
  • State the null hypothesis for a significance test about a population mean.
  • State the alternative hypothesis that matches the question of interest.
  • Distinguish between one-sided and two-sided alternatives for tests about μ.
  • Identify a one-sample t-test as the correct procedure for testing a single population mean.
  • Check the randomization, 10%, and Nearly Normal conditions for a significance test for a population mean.
Essential Knowledge:
  • A significance test evaluates a claim about a population parameter and asks whether the observed evidence would be unusual if the null hypothesis were true.
  • The null hypothesis is written with equality using the population parameter μ and a hypothesized value.
  • The alternative hypothesis uses a strict inequality: less than, greater than, or not equal to.
  • The form of the alternative hypothesis is determined by the research question and should be chosen before data are collected.
  • Hypotheses should refer to the population mean, not a sample statistic such as x̄.
  • For a one-sample test about μ, check for a random sample or randomized experiment, verify the 10% condition when sampling without replacement, and use either a large sample or sample data with no strong skewness or outliers.

Key Vocabulary

Significance Test A procedure used to test a claim about a population parameter by asking whether the sample evidence is likely to occur by chance alone.
Null Hypothesis The statement of equality that represents no difference, no change, or the claimed value for the population mean.
Alternative Hypothesis The claim the data are intended to support; it uses a strict inequality.
Null Value The hypothesized value that appears in both the null and alternative hypotheses.
One-Sided Alternative An alternative hypothesis of the form μ < value or μ > value.
Two-Sided Alternative An alternative hypothesis of the form μ ≠ value.
One-Sample t-Test The inference procedure used to test a claim about one population mean when the population standard deviation is unknown.
Conditions for Inference The assumptions that must be checked before carrying out the one-sample t-test.

Key Takeaways

[Summary]
  1. Write hypotheses using the population mean μ, not the sample mean x̄.
  2. The null hypothesis uses equality, and the alternative uses a strict inequality chosen to match the research question.
  3. Use a one-sample t-test to test a claim about one population mean.
  4. Before testing, verify randomization, the 10% condition, and an appropriate shape condition in context.
