AP Statistics Unit 9 Inference for Quantitative Data: Slopes

Topic 9.1: Introducing Statistics: Do Those Points Align?

Using Simulation to Decide Whether a Sample Slope Is Consistent with an Older Population Regression Model
Video Follow-Along Worksheet
Learning Objectives:
  • Describe the inferential question behind comparing a sample regression slope to a population regression model.
  • Explain why sample regression line slopes vary from sample to sample because of random variation.
  • Use repeated random samples to build a simulated sampling distribution of slope values.
  • Estimate how likely an observed sample slope would be if a population regression model were still valid.
  • Use an estimated probability to decide whether a population regression model is believable in context.
Essential Knowledge:
  • A sample regression line slope will usually differ from the population regression slope because of random sampling variation.
  • Simulation can model what slopes we would expect from repeated random samples if a population regression model is true.
  • Each simulated sample produces a sample regression line and one slope value.
  • Repeating the simulation many times builds a sampling distribution of the slope.
  • An observed slope that falls far out in the simulated distribution is considered unusual under the model.
  • If the estimated probability of getting a slope that unusual is about 0, the old population regression model is not believable for the new setting.
  • Conclusions should be stated in context by referring to duration, wait time, and whether the older Old Faithful model still seems valid in 2019.

Key Vocabulary

Population Regression ModelThe regression relationship for the full population, used to predict a response from an explanatory variable.
Population Regression LineThe least-squares regression line for all points in the population.
Sample Regression LineThe least-squares regression line calculated from sample data.
SlopeThe amount the predicted response changes for each 1-unit increase in the explanatory variable.
Random VariationNatural sample-to-sample differences that occur just by chance when taking random samples.
Simulated Random SampleA computer-generated sample taken from the population to imitate the random sampling process.
Sampling Distribution of the SlopeThe distribution of slope values from many repeated random samples of the same size.
Unusual / SurprisingDescription for a sample statistic that falls far from the center of the distribution expected under a model.
Estimated ProbabilityThe proportion of simulated results that are at least as extreme as the observed result.
BelievableA way to describe whether the observed sample result seems plausible if the population model is true.
DurationIn the Old Faithful example, the length of the current eruption in minutes.
Wait TimeIn the Old Faithful example, the number of minutes until the next eruption.

Key Takeaways

[Summary]
  1. Sample regression slopes vary from sample to sample because of random variation.
  2. Simulation shows what slope values are plausible if a population regression model is true.
  3. Each repeated random sample gives a new sample regression line and one slope value.
  4. Those repeated slope values form a simulated sampling distribution of the slope.
  5. If an observed slope falls far from the center of that distribution and has estimated probability about 0, the old model is not believable in context.
