AP Statistics Unit 1 Quantitative Data

Topic 1.10: which is about normal

Percentiles, z-Scores, and the Normal Distribution
Video Follow-Along Worksheet
Learning Objectives:
  • Use percentiles to describe the position of a value in a quantitative data set.
  • Use standardized scores to describe the relative position of a value.
  • Interpret z-scores as numbers of standard deviations above or below the mean.
  • Recognize that percentiles and z-scores can be calculated for any distribution, not only normal ones.
  • Describe a normal distribution as mound-shaped, symmetric, and determined by a mean and standard deviation.
  • Use the empirical rule to estimate the percent of data values in common normal intervals.
  • Use z-scores and Table A to find areas to the left, to the right, and between two values in a normal distribution.
  • Work backward from a proportion to find a value in a normal distribution.
Essential Knowledge:
  • A percentile is the percent of data values less than or equal to a given value.
  • A z-score measures distance from the mean in units of standard deviation.
  • A positive z-score indicates a value above the mean, and a negative z-score indicates a value below the mean.
  • A normal distribution is a symmetric, bell-shaped model for quantitative data.
  • Normal distributions are determined by the mean μ and standard deviation σ.
  • The empirical rule says about 68%, 95%, and 99.7% of values lie within 1, 2, and 3 standard deviations of the mean.
  • Table A gives the area to the left of a z-score on the standard normal distribution.
  • For right-tail areas, subtract from 1; for areas between two values, subtract two left-tail areas.
  • To work backward from an area, find the corresponding z-score in Table A and solve for the unknown value.

Key Vocabulary

Relative PositionWhere a value falls compared with the rest of a quantitative data set.
PercentileThe percent of data values less than or equal to a given value.
Standardized ScoreA measure of position that uses the mean and standard deviation.
z-scoreThe number of standard deviations a value is above or below the mean.
Normal DistributionA mound-shaped, symmetric distribution often used as a model for quantitative data.
Bell CurveA common informal name for the normal distribution.
Empirical RuleThe 68-95-99.7 rule for normal distributions.
μ (mu)The symbol used for the mean of a normal distribution.
σ (sigma)The symbol used for the standard deviation of a normal distribution.
Table AThe standard normal probability table that gives area to the left of a z-score.
Area to the LeftThe proportion of values below a given boundary in a normal distribution.
Area to the RightThe proportion of values above a given boundary in a normal distribution.
Area BetweenThe proportion of values between two boundaries in a normal distribution.
Working BackwardFinding a data value from a given area or percentile in a normal distribution.
