Topic 1.5: Topic 1.5

Representing a Quantitative Variable with Graphs
Video Follow-Along Worksheet
Learning Objectives:
  • Classify quantitative variables as discrete or continuous.
  • Distinguish between counted quantities and measured quantities.
  • Represent quantitative data with dotplots, stem-and-leaf plots, and histograms.
  • Describe the advantages and disadvantages of common graphs for quantitative data.
  • Explain how changing histogram interval widths can change the display.
Essential Knowledge:
  • A discrete variable can take on a countable number of values and has gaps between possible values.
  • A continuous variable can take on infinitely many values with no gaps between possible values.
  • Discrete variables usually come from counting, while continuous variables usually come from measuring.
  • A dotplot shows each observation as a dot and makes the shape of a distribution easy to see.
  • A stem-and-leaf plot splits each value into a stem and a leaf and also shows individual values.
  • A histogram groups data into intervals, and the height of each bar shows how many observations fall in that interval.
  • Changing histogram interval widths can change the appearance of the graph.
  • Dotplots and stem-and-leaf plots are harder to make for very large data sets.
  • Histograms are useful for large data sets but do not show each individual value.

Key Vocabulary

Quantitative VariableA variable that takes numerical values for a measured or counted quantity.
Discrete VariableA quantitative variable with countable values and gaps between possible values.
Continuous VariableA quantitative variable with infinitely many possible values and no gaps.
DotplotA graph that represents each observation with a dot above its value.
StemThe leading digit or digits in a stem-and-leaf plot.
LeafThe final digit, usually written to the right of the stem.
Split StemA stem that is divided into two rows when one stem has many values.
HistogramA graph that groups quantitative data into intervals and shows counts or proportions.
Interval / BinA range of values used for one bar in a histogram.
ShapeThe overall pattern of a distribution shown by a graph.
