Topic 6.5: Interpreting p-Values

Calculating Test Statistics, Calculating & Interpreting p-Values
Video Follow-Along Worksheet
Learning Objectives:
  • VAR-6.G: Calculate a test statistic for a test about a population proportion.
  • VAR-6.H: Calculate a p-value for a test about a population proportion.
  • VAR-6.I: Interpret the p-value of a significance test for a population proportion.
Essential Knowledge:
  • The standardized test statistic is z = (p − p0) / √(p0(1 − p0) / n).
  • The p-value is the probability of getting evidence as extreme or more extreme than observed, assuming H0 is true.
  • One-sided tests: area in one tail. Two-sided tests: area in both tails (double the one-tail area).

Key Vocabulary

Standardized Test Statistic (statistic − null value) / standard deviation of statistic. Measures how far the sample result is from the null value in standard-deviation units.
p-value The probability of obtaining evidence for Ha as strong as or stronger than the observed evidence, by chance alone, when H0 is true.
Standard Error An estimate of the standard deviation of a statistic. For a significance test, we use p0 (not p) since we assume H0 is true.
One-Sided p-value Area in one tail of the standard normal distribution (Ha uses < or >).
Two-Sided p-value Area in both tails of the standard normal distribution (Ha uses ≠). Calculated as 2 × (one-tail area).
