# Registry Integration Spec

## Goal

The AP Stats roadmap app (`ap_stats_roadmap_square_mode.html`) should display all lesson materials when a day is clicked — worksheets, drills, quizzes, blookets, videos, and Schoology folder links. The data source is the **lesson registry** maintained by the pipeline in the Agent repo.

## Data Source

**File:** `C:/Users/rober/Downloads/Projects/Agent/state/lesson-registry.json`

**Format:** JSON object keyed by `"unit.lesson"` (e.g., `"6.10"`). Each entry contains:

```json
{
  "unit": 6,
  "lesson": 10,
  "topic": "Topic 6.10",
  "urls": {
    "worksheet": "https://robjohncolson.github.io/apstats-live-worksheet/u6_lesson10_live.html",
    "drills": "https://lrsl-driller.vercel.app/platform/app.html?c=apstats-u6-inference-prop&level=l17-hypotheses-610",
    "quiz": "https://robjohncolson.github.io/curriculum_render/?u=6&l=9",
    "blooket": "https://dashboard.blooket.com/set/69ad1cce0d5874349dbbf688",
    "schoologyFolder": "https://lynnschools.schoology.com/course/7945275782/materials?f=986400679",
    "videos": ["1dIRMyHdePpkx7pCJFcAkRHIPj2Q8RtqG", "1SDYELDZa9kcJldq_qf1DsOOMhrjzfkio"]
  },
  "status": {
    "ingest": "done",
    "worksheet": "done",
    "drills": "done",
    "blooketCsv": "done",
    "blooketUpload": "done",
    "schoology": "done"
  }
}
```

### URL types

| Key | What it is | URL pattern |
|-----|-----------|-------------|
| `worksheet` | Live follow-along worksheet (HTML) | `robjohncolson.github.io/apstats-live-worksheet/u{U}_lesson{L}_live.html` |
| `drills` | Spaced-repetition drill platform | `lrsl-driller.vercel.app/platform/app.html?c=...&level=...` |
| `quiz` | Curriculum render quiz (previous lesson) | `robjohncolson.github.io/curriculum_render/?u={U}&l={L-1}` |
| `blooket` | Blooket review set | `dashboard.blooket.com/set/{id}` |
| `schoologyFolder` | Schoology day folder | `lynnschools.schoology.com/course/.../materials?f={id}` |
| `videos` | Google Drive video file IDs (array) | Construct URL: `https://drive.google.com/file/d/{id}/view` |

### Key-to-topic mapping

The roadmap app uses topic codes like `"6.6"` in the schedule data (`inf.t`). The registry uses `"unit.lesson"` keys like `"6.6"`. These are the **same format** — direct lookup with no conversion needed.

## Integration Approach: Sidecar JS File

A sidecar JS file (`lesson-registry-data.js`) lives next to the roadmap HTML. The pipeline exports it from the registry. The HTML loads it via `<script>` — if the file doesn't exist, the tag 404s silently and everything works as it does today.

### Sidecar file: `lesson-registry-data.js`

```javascript
// Auto-generated by Agent/scripts/export-registry.mjs — do not edit
const LESSON_REGISTRY = {
  "6.10": {
    "unit": 6, "lesson": 10,
    "urls": {
      "worksheet": "https://robjohncolson.github.io/apstats-live-worksheet/u6_lesson10_live.html",
      "drills": "https://lrsl-driller.vercel.app/platform/app.html?c=...&level=...",
      "quiz": "https://robjohncolson.github.io/curriculum_render/?u=6&l=9",
      "blooket": "https://dashboard.blooket.com/set/69ad1cce0d5874349dbbf688",
      "schoologyFolder": "https://lynnschools.schoology.com/course/.../materials?f=...",
      "videos": ["driveFileId1", "driveFileId2"]
    },
    "status": { "worksheet": "done", "drills": "done", "blooketUpload": "done" }
  },
  // ... more lessons

```

### Export script

Lives in the Agent repo. Reads `lesson-registry.json`, writes the JS file to the follow-alongs directory.

```bash
# Run from Agent repo
node scripts/export-registry.mjs

# Default output: ../school/follow-alongs/lesson-registry-data.js
# Custom output:
node scripts/export-registry.mjs --out /path/to/lesson-registry-data.js
```

The export should:
- Strip fields the roadmap doesn't need (timestamps, schoologyLinks details)
- Keep only `urls` and `status` per entry (plus `unit`/`lesson` for reference)
- Write as `const LESSON_REGISTRY = ...;` (not a module — plain script tag)

### When to re-export

Run the export after pipeline runs add new lesson data:
```bash
cd Agent && node scripts/export-registry.mjs
```

This will be automated in the pipeline eventually (as a final step of `lesson-prep.mjs`).

### HTML changes

**1. Script tag** — add before the main `<script>` block:
```html
<script src="lesson-registry-data.js"></script>
```
If the file is missing, the browser logs a 404 to console but execution continues. `LESSON_REGISTRY` remains `undefined`.

**2. Registry lookup helper** — add near `lookupTopic()`:
```javascript
function lookupRegistry(topicCode) {
  // topicCode is e.g. "6.6" — same format as registry keys
  if (typeof LESSON_REGISTRY === 'undefined') return null;
  return LESSON_REGISTRY[topicCode] || null;
}
```

**3. Merge in showResourcePanel()** — after looking up `RESOURCES[topicId]`:
```javascript
const regEntry = lookupRegistry(inf.t);

// Registry links (only shown when status confirms they're ready)
if (regEntry?.urls) {
  const u = regEntry.urls;
  const s = regEntry.status || {};

  if (u.worksheet && s.worksheet === "done")
    // add "Follow-Along Worksheet" link
  if (u.drills && s.drills === "done")
    // add "Practice Drills" link
  if (u.quiz)
    // add "Quiz (Previous Lesson)" link
  if (u.blooket && s.blooketUpload === "done")
    // add "Blooket Review" link
  if (u.videos?.length)
    // add "Video 1", "Video 2" links (Google Drive URLs)
  if (u.schoologyFolder)
    // add "View on Schoology" link
}
```

### Merge priority

| Field | Registry has it? | RESOURCES has it? | Show |
|-------|-----------------|-------------------|------|
| Worksheet link | yes (status=done) | no | Registry |
| Drills link | yes (status=done) | no | Registry |
| Blooket link | yes (status=done) | yes (different URL) | Both — registry is the uploaded set, RESOURCES may have a different one |
| AP Classroom video | no | yes | RESOURCES |
| Google Drive video | yes (IDs in array) | yes (as `altUrl`) | Registry (deduplicate with RESOURCES `altUrl` if same ID) |
| PDF link | no | yes | RESOURCES |
| Schoology folder | yes | no | Registry |
| Quiz link | yes | no | Registry |

**Rule:** Registry wins for fields where it has a URL and `status === "done"`. RESOURCES fills everything else. No data is discarded.

### No-file fallback

If `lesson-registry-data.js` doesn't exist:
- Browser logs a 404 to console (no user-visible error)
- `typeof LESSON_REGISTRY === 'undefined'` → `lookupRegistry()` returns null
- `showResourcePanel()` shows only RESOURCES data — identical to current behavior
- Zero regression risk

## What the Resource Panel Should Show (per lesson)

When a day is clicked, the merged panel displays:

| Section | Source | Link text | Condition |
|---------|--------|-----------|-----------|
| Worksheet | `registry.urls.worksheet` | "Follow-Along Worksheet" | `status.worksheet === "done"` |
| Drills | `registry.urls.drills` | "Practice Drills" | `status.drills === "done"` |
| Quiz | `registry.urls.quiz` | "Quiz (Previous Lesson)" | always if URL exists |
| Blooket | `registry.urls.blooket` | "Blooket Review" | `status.blooketUpload === "done"` |
| Videos (AP Classroom) | `RESOURCES.videos[].url` | "AP Classroom Video 1", etc. | from hardcoded RESOURCES |
| Videos (Google Drive) | `registry.urls.videos[]` | "Google Drive Video 1", etc. | always if array non-empty |
| PDFs | `RESOURCES.pdfs[].url` | label from RESOURCES | from hardcoded RESOURCES |
| Schoology | `registry.urls.schoologyFolder` | "View on Schoology" | if URL exists |

Fall back to hardcoded `RESOURCES` for any field the registry doesn't have.

## Registry API (for reference)

The registry is managed by `Agent/scripts/lib/lesson-registry.mjs`. Key functions:

- `getLesson(unit, lesson)` → full entry or null
- `computeUrls(unit, lesson)` → generates default URLs from unit/lesson numbers
- `updateUrl(unit, lesson, key, value)` → update one URL field
- `loadRegistry()` → returns entire registry object

The registry file is at: `Agent/state/lesson-registry.json`

## Pipeline Context

The registry gets populated by the lesson-prep pipeline (`Agent/scripts/lesson-prep.mjs`):
1. **Ingest** — scrapes video IDs from Google Drive
2. **Worksheet** — generates live worksheet HTML
3. **Drills** — generates drill cartridge
4. **Blooket** — generates and uploads Blooket CSV
5. **Schoology** — posts links to Schoology folders

Each step updates the registry's `urls` and `status` fields. After a full pipeline run, the registry has all URLs for that lesson. The `--heal` flag can rediscover and reconcile missing data.
