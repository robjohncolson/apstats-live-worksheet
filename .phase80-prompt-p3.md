Phase 80-3: Find REAL function entries in the 0x05e4xx text-rendering family (TI-84 CE ROM transpilation)

## Context
Phase 78 found that 0x05e7d2, 0x05e481, 0x09cb14 render legible top-strip text when probed as entry points. Phase 79 confirmed these are MID-function blocks (zero direct callers) inside a text-rendering family at 0x05e400-0x05e820 that uses 0x05e242 as a per-char printer.

**Goal**: Find the REAL function entries of this family. The functions include:
- 0x05e242 (per-char printer, takes A=char)
- 0x05e402 (string printer with special-char handling, calls 0x05e3e8)
- 0x05e448 (string printer with register save/restore, calls 0x05e242)
- 0x05e7cd (iterative loop: call 0x05e242 / ret z / call 0x0a2b72 / loop)
- 0x05e7a4 (cursor setup wrapper: call 0x05e381 / jr z / inc hl / push hl / call 0x05e7e3)

These are block ADDRESSES in PRELIFTED_BLOCKS, but some may not be function entries. The real entries are found by scanning for CALLERS of these blocks.

## Deliverables

### 1. `probe-phase80-05e4xx-callers.mjs`
Node script that:
- Loads PRELIFTED_BLOCKS via `import(pathToFileURL(transpiledPath).href)` from `./ROM.transpiled.js`
- For each target address in `[0x05e242, 0x05e402, 0x05e448, 0x05e7cd, 0x05e7a4, 0x05e381, 0x05e3e8, 0x05e7e3, 0x05e27e, 0x05e490]`, scan blocks for:
  - `exits` containing `{ type: 'call', target: <address> }`
- For each hit, output: caller block address, dasm of caller block's instructions (via `block.instructions[].dasm`), and the immediate predecessor block (via fallthrough/branch exit scan).
- Also report: how many distinct functions call into the 0x05e4xx region from OUTSIDE it (non-0x05e4xx caller addresses).

### 2. `phase80-3-05e4xx-callers-report.md`
- For each target: table of callers with their dasm
- "External callers" section: blocks OUTSIDE the 0x05e4xx region that call into it (these are the top-level screens that use this text-rendering family)
- Verdict: for each external caller, hypothesize which screen/dialog uses this text-rendering pattern (e.g., program editor, solver prompt, etc.)
