AP Statistics Unit 2 Exploring Two-Variable Data

Topic 2.6: Required Course Content

Linear Regression Models
Video Follow-Along Worksheet
Learning Objectives:
  • Construct and read a simple linear regression model written in the form ŷ = a + bx.
  • Calculate a predicted response value using a linear regression model.
  • Interpret the roles of the slope, y-intercept, explanatory variable, and predicted response in context.
  • Explain that regression output gives predicted values, not exact observed values.
  • Determine when a prediction is extrapolation and judge whether that prediction is reliable.
Essential Knowledge:
  • A simple linear regression model is an equation that uses an explanatory variable, x, to predict a response variable, y.
  • The predicted response is written as ŷ.
  • In the model ŷ = a + bx, a is the y-intercept and b is the slope.
  • Technology is commonly used to generate and use a regression model.
  • Extrapolation means predicting a response using an x-value outside the interval used to build the regression line.
  • Predictions made by extrapolation are less reliable because the trend may not continue beyond the observed data range.

Key Vocabulary

Linear Regression ModelAn equation that uses an explanatory variable to predict a response variable.
Predicted ResponseThe model's estimated y-value, written as ŷ.
SlopeThe amount the predicted response changes for each one-unit increase in x.
Y-InterceptThe predicted response when x = 0.
Explanatory VariableThe x-variable used to help predict the response.
Response VariableThe y-variable being predicted.
Regression LineThe line given by the linear regression model.
PredictionAn estimated value from the model rather than an exact observed value.
Observed ValueAn actual value recorded in the data set.
ExtrapolationUsing the model to predict beyond the interval of observed x-values.
ReliabilityHow trustworthy a prediction is likely to be.
Interval of x-valuesThe range of explanatory-variable values used to create the model.
