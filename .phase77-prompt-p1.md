## Context
Phase 74 discovered that "Normal"/"Float"/"Radian" mode names are stored in the TI-BASIC token name table at 0x0a0450 as `<token_code><length><name>` entries (0x4F=Normal, 0x52=Float, etc.). ## Deliverables (all files in TI-84_Plus_CE/)

### 1. `probe-phase77a-refined-walker.mjs`
Node script that:
- Loads ROM.transpiled.js via dynamic `import(pathToFileURL(transpiledPath).href)`. The module exports `PRELIFTED_BLOCKS` (keyed by `hexAddr_mode`, each value has `dasm` string of newline-separated instructions, `entry` address, plus metadata).
- Scans PRELIFTED_BLOCKS for candidate "short walker" functions. A candidate is a connected block group (starting at a function entry) that:
  - Calls `0x0059c6` (char print) at least TWICE. A call shows up in `dasm` as `call 0x0059c6` or `CALL 0x0059c6`.
  - Total block count under 10 (short function).
  - Ends in `ret` (at least one block contains only `ret` or ends in `ret`).
  - Has `inc hl` somewhere between two calls OR the second call is preceded by `ld a, (hl)` / `ld a,(hl)`.
- You can approximate "function entry" by taking each block whose `entry` field matches `(block.entry & ~0) === block.entry` and walking connected blocks via the `exits` / `successors` field of the block. Inspect the ROM.transpiled.js schema by doing a quick `Object.keys(firstBlock)` probe at runtime.
- Rank candidates by: `(numberOf0x0059c6Calls * 2) + (hasIncHlBetweenCalls ? 3 : 0) - blockCount`
- For the top 15 candidates: invoke each as a function entry via `createExecutor` with HL=0x0a0452 (the "prgm" token name start), A=0x4C (prgm token code), IY=0xD00080, and the standard OS-init prelude (boot → 0x08c331 → SetTextFgColor 0x0802b2 → probe).
- For each probe: count VRAM writes (diff from 0xAAAA sentinel at 0xd40000-0xd4f000 for 320x240x2 bytes), report `drawn` count, fg count (pixel value not bg), bg count (pixel value bg=0xFFFF after text), bounding box of non-sentinel writes, and first 10 blocks executed.
- Cap `maxSteps` at 12000.

### 2. `phase77a-refined-walker-report.md`
Markdown report with:
- Candidate list: top 15 with entry addr, block count, number of 0x0059c6 calls, whether `inc hl` is present between calls, score, first ~8 dasm lines
- Probe results table: | entry | drawn | fg | bg | bbox | verdict |
- Verdict section: which (if any) looks like a token-name printer (a "hit" is something with drawn > 10 and fg/bg ratio suggesting text)
