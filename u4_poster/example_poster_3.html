Expected value, standard deviation, and the #1 AP Exam mistake
📐 KEY FORMULAS
μₓ = E(X) = Σ xᵢ · P(xᵢ)
Expected Value (Mean)
σₓ = √[Σ (xᵢ − μ)² · P(xᵢ)]
Standard Deviation
μᵧ = a + b·μₓ  |  σᵧ = |b|·σₓ
Linear Transform Y = a + bX (constant doesn't affect SD!)
μₓ₊ᵧ = μₓ + μᵧ  |  μₓ₋ᵧ = μₓ − μᵧ
Combining Means (works normally ✓)

🚨 THE VARIANCE TRAP — #1 AP EXAM MISTAKE! 🚨

When combining independent random variables:

σₓ₊ᵧ = √(σₓ² + σᵧ²)     AND     σₓ₋ᵧ = √(σₓ² + σᵧ²)
Variances ALWAYS ADD — even for subtraction! SDs NEVER add directly!

❌ WRONG WAY

σₓ₊ᵧ = σₓ + σᵧ
= 3 + 4 = 7

NEVER DO THIS!

✓ RIGHT WAY

σₓ₊ᵧ = √(σₓ² + σᵧ²)
= √(3² + 4²) = √(9+16) = √25 = 5

Square → Add → Square Root!

✏️ WORKED EXAMPLE
Problem: At a coffee shop: Coffee costs μ = $4.00, σ = $0.50. Muffin costs μ = $3.00, σ = $0.75. Assume costs are independent. Find the mean and SD of the total cost.
Mean of Total (Easy!)
μ_total = μ_coffee + μ_muffin
= $4.00 + $3.00
= $7.00 ✓
Mean total cost = $7.00
SD of Total (THE TRAP!)
❌ WRONG: 0.50 + 0.75 = $1.25
✓ RIGHT:
σ = √(0.50² + 0.75²)
= √(0.25 + 0.5625)
= √0.8125 ≈ $0.90
SD of total = $0.90
⚠️ MORE TRAPS TO AVOID!
  • For X − Y, variances STILL ADD! Don't subtract — ever!
  • Adding a constant (like +$0.50) changes mean but NOT SD
  • Multiplying by constant changes BOTH mean and SD
  • These formulas require INDEPENDENCE!
  • Why does variance add for subtraction? Subtracting uncertain things makes MORE uncertainty!
  • σ ≠ σ² ! Don't confuse SD with variance
