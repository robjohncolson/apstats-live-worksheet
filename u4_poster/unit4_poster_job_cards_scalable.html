📊 Quick Reference by Class Size:

  • 7 students: Cards 1, 2, 3, 4, 5, 6, 7
  • 8 students: Cards 1, 2, 3A, 3B, 4, 5, 6, 7
  • 9 students: Cards 1, 2, 3A, 3B, 4, 5, 6, 7 + (give 2 students same card OR double up QC)
  • 10 students: Cards 1, 2A, 2B, 3A, 3B, 4, 5, 6, 7 + one duplicate
  • 11 students: Cards 1, 2A, 2B, 3A, 3B, 4, 5, 6, 7 + two duplicates
  • 12-13 students: Add 3C (Example Finisher) and 8 (Decorator)
  • 14-15 students: Add 9 (Visual Artist 2)

💡 Pro Tips:

  • When duplicating cards, assign to different starting posters
  • Quality Control (#7) is great to duplicate — more eyes = fewer errors
  • If odd number, have one student be a "floater" who helps whoever needs it
CORE
#1
📝 TITLE WRITER

Your Job at EACH Poster:

  • Write poster title in LARGE letters at top
  • Add topic numbers (e.g., "4.1 – 4.3")
  • Write 1-line summary of the section
  • Make it readable from across the room!
Titles to Write: 🔵 P1: "Simulation & Basic Probability" (4.1-4.3)
🟣 P2: "Conditional Prob & Independence" (4.4-4.6)
🔴 P3: "Random Variables & THE VARIANCE TRAP" (4.7-4.9)
🟢 P4: "Binomial & Geometric" (4.10-4.12)
⏱️ ~15 min per poster → Rotate on signal → ALL 4 posters
CORE
#2
🔢 FORMULA SCRIBE

Your Job at EACH Poster:

  • Write ALL key formulas for that topic
  • Draw a box around each formula
  • Label what each formula is for
  • Use ruler for fraction bars!
Key Formulas (see reference sheet): 🔵 P1: Complement, sum to 1, basic probability
🟣 P2: Conditional, multiplication, addition rules
🔴 P3: E(X), σ, combining RVs — THE TRAP!
🟢 P4: Binomial + Geometric formulas
⏱️ ~15 min per poster → Rotate on signal → ALL 4 posters
CORE
#3
✏️ EXAMPLE WRITER

Your Job at EACH Poster:

  • Write the example problem
  • Show step-by-step work
  • Box the final answer in green
  • Write answer in context (sentence!)
Problems (see reference sheet): 🔵 P1: Free throw simulation (70%, 5 shots)
🟣 P2: Two-way table (sports & instruments)
🔴 P3: Coffee + Muffin — show WRONG vs RIGHT!
🟢 P4: Binomial (80%, 10 shots) + Geometric (15%)
⏱️ ~15 min per poster → Rotate on signal → ALL 4 posters
CORE
#4
🎨 VISUAL ARTIST

Your Job at EACH Poster:

  • Draw the required diagram/table/chart
  • Use RULER for straight lines
  • Label all parts clearly
  • Use color to make it pop!
Required Visuals: 🔵 P1: Tree diagram (2 free throws)
🟣 P2: Two-way table (filled in with numbers)
🔴 P3: WRONG vs RIGHT comparison box
🟢 P4: Binomial vs Geometric comparison table
⏱️ ~15 min per poster → Rotate on signal → ALL 4 posters
CORE
#5
⚠️ TRAP SPOTTER

Your Job at EACH Poster:

  • Create the "WATCH OUT!" box
  • List 2-3 common mistakes
  • Explain why each is wrong
  • Use ❌ and ✓ symbols!
Key Traps: 🔵 P1: Simulation ≠ exact answer
🟣 P2: P(A|B) ≠ P(B|A)!
🔴 P3: DON'T ADD SDs DIRECTLY!!!
🟢 P4: pdf vs cdf, "at least" needs complement
⏱️ ~15 min per poster → Rotate on signal → ALL 4 posters
CORE
#6
📱 CALCULATOR GUIDE

Your Job at EACH Poster:

  • Write TI-84 keystrokes needed
  • Show menu path (e.g., MATH → PRB)
  • Write syntax with actual numbers
  • Test it on your calculator first!
Calculator Functions: 🔵 P1: randInt(0,9) or randInt(1,10,5)
🟣 P2: (mostly manual calculation)
🔴 P3: 1-Var Stats L1, L2
🟢 P4: binompdf/cdf, geometpdf/cdf
⏱️ ~15 min per poster → Rotate on signal → ALL 4 posters
