AP Statistics Unit 9 Inference for Quantitative Data: Slopes

Topic 9.5: Carrying Out a Test for the Slope of a Regression Model

Calculating the Test Statistic and p-value, Interpreting the p-value, and Writing a Conclusion for a Test About Slope
Video Follow-Along Worksheet
Learning Objectives:
  • Calculate the standardized test statistic for a significance test about the slope of a population regression line.
  • Use the correct degrees of freedom and the correct tail or tails to find a p-value for a test about slope.
  • Recognize when computer output gives a two-sided p-value and adjust for a one-sided test when needed.
  • Interpret a p-value in context for a significance test about slope.
  • Compare the p-value to α to decide whether to reject H0 or fail to reject H0.
  • Write a full conclusion in context for a significance test about a slope.
  • Carry out a complete significance test about the slope of a regression model from start to finish.
Essential Knowledge:
  • For a test about slope, the test statistic is t = (b - β0) / SEb, where β0 is the null value of the slope.
  • If computer output includes a T column, you can usually read the test statistic directly from the row for the explanatory variable.
  • P-values for tests about slope use a t-distribution with degrees of freedom n - 2.
  • A one-sided alternative uses one tail of the distribution, while a two-sided alternative uses both tails.
  • Computer output often reports a two-sided p-value, so a one-sided p-value may require dividing that value by 2.
  • The p-value is the probability of getting evidence for Ha as strong as or stronger than the sample result by chance alone when H0 is true.
  • If the p-value is less than or equal to α, reject H0 and conclude there is convincing statistical evidence for Ha in context.
  • If the p-value is greater than α, fail to reject H0 and conclude there is not convincing statistical evidence for Ha in context.
  • Smaller p-values and more extreme t-statistics provide stronger evidence against H0.
  • A complete significance test includes hypotheses, parameter definition, significance level, procedure, conditions, test statistic, p-value, and conclusion.

Key Vocabulary

Sample Slope (b)The slope of the least-squares regression line calculated from the sample data.
Standard Error of the SlopeThe estimated standard deviation of the sample slope in repeated sampling.
Standardized Test StatisticA value that measures how far the sample statistic is from the null value in standard error units.
t-DistributionThe distribution used to calculate p-values for tests about slope when conditions are met.
Degrees of FreedomFor a test about slope, the number n - 2 used with the t-distribution.
One-Sided TestA test that looks for evidence in one direction only, using a single tail of the distribution.
Two-Sided TestA test that looks for evidence in either direction, using both tails of the distribution.
p-valueThe probability, assuming H0 is true, of getting a result as extreme or more extreme than the observed one.
Reject H0The decision made when the p-value is small enough to give convincing evidence for the alternative hypothesis.
Fail to Reject H0The decision made when the p-value is too large to give convincing evidence for the alternative hypothesis.
Convincing Statistical EvidenceLanguage used in a conclusion when the p-value is at or below the significance level.
As Extreme or More ExtremeThe part of a p-value interpretation that describes outcomes at least as far from the null value as the sample result.
