🚀 From Code to Website in 90 Minutes

Use AI to build a real website—no experience needed!

What You'll Do Today

By the end of this workshop, you'll have a real website on the internet that anyone can visit!

Create GitHub Repo → Ask AI to Write Code → Save & Upload → Publish Website!

Phase 1 Set Up Your GitHub Repository ~15 min

A "repository" (or "repo") is like a folder on GitHub that stores your project files.

Step 1.1 — Create a New Repository

1

Go to GitHub and sign in:

Open GitHub →
2

Click the + icon in the top-right corner, then click "New repository"

3

Fill in the details:

  • Repository name: my-first-website (or choose your own!)
  • Description: "My first website built with AI" (optional)
  • Public ← Select this (required for free websites)
  • ☑️ Add a README file ← Check this box!
4

Click the green "Create repository" button

✓ Checkpoint: You should now see your new repository page with a README.md file!

Step 1.2 — Create a Personal Access Token (Your Password for Git)

GitHub needs a special password called a "token" to let you upload code from your computer.

1

Go to GitHub's token settings:

Open Token Settings →
2

Click "Generate new token" → "Generate new token (classic)"

3

Fill in the settings:

  • Note: School laptop Git access
  • Expiration: 90 days (or "Custom" → end of semester)
  • Select scopes: Check the box for ☑️ repo (this gives full access to your repositories)
4

Scroll down and click "Generate token"

5

IMPORTANT: Copy the token immediately! It starts with ghp_

Paste it somewhere safe (a text file, your notes app, etc.)

⚠️ You can only see this token ONCE! If you lose it, you'll have to create a new one. Save it now!

Step 1.3 — Clone Your Repository

"Cloning" downloads your GitHub repository to your computer so you can add files to it.

1

On your repository page, click the green "<> Code" button

Copy the HTTPS URL (it looks like https://github.com/yourusername/my-first-website.git)

2

Open Git Bash (from your PortableGit folder, double-click git-bash.exe)

3

Navigate to your Documents folder:

cd ~/Documents
4

Clone your repository (replace the URL with yours):

git clone https://github.com/YOUR-USERNAME/my-first-website.git
5

Enter your project folder:

cd my-first-website
✓ Checkpoint: Type ls and press Enter. You should see README.md listed!

Step 2.4 — Save the Code to a File

Claude will respond with HTML code. Now let's turn it into a real file!

1

Look for the code block in Claude's response (it has a gray background)

Click the "Copy" button in the top-right corner of the code block

2

Open Notepad on your computer:

  • Press the Windows key
  • Type "Notepad"
  • Press Enter
3

Paste the code into Notepad (Ctrl + V)

4

Save the file correctly:

  • Press Ctrl + S (or File → Save)
  • Navigate to: Documents → my-first-website folder
  • Change "Save as type" to: All Files (*.*)
  • File name: index.html
  • Click Save
⚠️ IMPORTANT: The file MUST be named index.html (not index.html.txt). Make sure "Save as type" is set to "All Files"!
💡 Test it locally first! Open File Explorer, go to your project folder, and double-click index.html. It should open in your browser!

Phase 3 Upload to GitHub ~10 min

Now let's upload your website to GitHub using the Git commands!

1

In Git Bash, make sure you're in your project folder:

cd ~/Documents/my-first-website
2

Stage your files (tell Git which files to save):

git add .

The dot means "all files in this folder"

3

Commit your changes (save a snapshot with a message):

git commit -m "Add my first website"
4

Push to GitHub (upload to the internet):

git push
5

When asked for credentials:

  • Username: Type your GitHub username, press Enter
  • Password: Paste your Personal Access Token (right-click to paste in Git Bash), press Enter

Note: You won't see the password as you paste it—that's normal!

✓ Checkpoint: Go to your repository on GitHub and refresh the page. You should see index.html listed!

Phase 4 Publish with GitHub Pages ~10 min

GitHub Pages turns your repository into a free website!

1

On your GitHub repository page, click "Settings" (tab near the top)

2

In the left sidebar, click "Pages"

3

Under "Branch", change "None" to "main"

Leave the folder as "/ (root)"

Click "Save"

4

Wait 1-3 minutes for GitHub to build your site

Refresh the Settings → Pages page. You'll see a green box with your URL!

🎉 Your website is LIVE! Your URL will look like this:
https://your-username.github.io/my-first-website/
💡 While you wait: Share your URL with classmates! Ask what projects they chose. Compare your designs!

🔧 Troubleshooting

My website shows a 404 error

  • Make sure your file is named exactly index.html (not index.html.txt)
  • Wait a few more minutes—GitHub Pages can be slow
  • Check that GitHub Pages is set to the "main" branch

Git says "Permission denied"

  • Make sure you're using your Personal Access Token as the password, not your regular GitHub password
  • Try generating a new token if the old one expired

My file saved as .txt instead of .html

  • In Notepad's Save dialog, change "Save as type" to "All Files (*.*)"
  • Manually type the full filename: index.html

Git says "nothing to commit"

  • You probably already committed! Try git push
  • Or check if you saved the file in the right folder
