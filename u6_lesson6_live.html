AP Statistics Unit 6 Inference for Proportions

Topic 6.6: Concluding a Test for a Population Proportion

Making Conclusions Using Significance Level & p-Values
Video Follow-Along Worksheet
Learning Objectives:
  • DAT-3.A: Make an appropriate conclusion for a significance test for a population proportion.
Essential Knowledge:
  • If the p-value ≤ α, we reject H0 and conclude there is convincing statistical evidence for Ha.
  • If the p-value > α, we fail to reject H0 and conclude there is not convincing statistical evidence for Ha.
  • Conclusions must explicitly compare the p-value to α and state the conclusion about Ha in context.
  • Never "accept" H0 and never say we have "proven" Ha.

Key Vocabulary

Significance Level (α) A predetermined boundary value used to determine if a p-value is small enough to reject H0. Common values: 0.05, 0.01, 0.10.
Reject H0 When the p-value ≤ α, we reject the null hypothesis and conclude there is convincing statistical evidence for Ha.
Fail to Reject H0 When the p-value > α, we fail to reject the null hypothesis and conclude there is not convincing statistical evidence for Ha.
Accepting the Null A common error: concluding that H0 is true when you fail to reject it. A lack of convincing evidence for Ha does not prove H0.

Key Takeaways

[Summary]
  1. If p-value ≤ α, we H0. Conclude: there is convincing statistical evidence that [state Ha in context].
  2. If p-value > α, we H0. Conclude: there is not convincing statistical evidence that [state Ha in context].
  3. Always explicitly the p-value to α in your conclusion.
  4. Never "accept" H0 and never say you have "proven" Ha.
